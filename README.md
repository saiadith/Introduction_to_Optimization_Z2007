## Official Repo for **Introduction to Optimization Z2007**

Contains relevant notebooks (and slides if applicable).

Please note that the notebooks typically are large and GitHub cannot allow the viewing of outputs directly - if you are looking for a way to see the outputs, please use "https://nbviewer.org/" and simply paste the notebook's GitHub URL in the relevant textbox and you should be able to play the animations.

e.g: https://github.com/saiadith/Introduction_to_Optimization_Z2007/blob/main/notebooks/1D_Search_Methods.ipynb -> https://nbviewer.org/github/saiadith/Introduction_to_Optimization_Z2007/blob/main/notebooks/1D_Search_Methods.ipynb


Under the **notebooks** tab, you will find the relevant programming implementations. Typically, the programming examples will try code (atleast simpler) algorithms from scratch - this is pretty useful to build the necessary intuition (and could potentially be asked in interviews - so highly recommend building the skills to do this). At the end, we would also highlight the existing scipy or torch alternatives that are typically used in production. This is what you would be using in day-to-day projects, later down the line.


**BONUS:** It is highly encouraged to go through relevant mathematical modules/libraries and try and contribute a solver for them. This is a good indicator of programming knowledge + mathematical understanding, and could count as an open source contribution, that we know is pretty useful :)
